# 🎮 Tic Tac Toe Game (Android)

A simple and interactive Tic Tac Toe (XO) game built for Android.  
This game allows two players to play on the same device with automatic win detection.

---

## 🚀 Features

- ❌⭕ Two-player mode
- 🧠 Automatic win detection
- 🔄 Game reset button
- 📱 Clean and responsive UI
- 🎯 Draw detection logic

---

## 🛠️ Tech Stack

- Kotlin / Java
- Android Studio
- XML Layout Design

---

## 🎮 Game Logic

- Players take turns placing X and O.
- The app checks for winning combinations after each move.
- Displays winner or draw result.
- Reset button starts a new game.
